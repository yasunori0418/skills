## 機能一覧

対応要求が `-` の行は「要求に紐づかない機能 = スコープ外混入」として機械検査が検出する。

## インターフェース

対象は関数・API・CLI 引数・ファイル書式・イベント・設定キーなど、境界を跨ぐもの全て。

### <インターフェース名>

- 提供元: <モジュール>
- 入力: <引数・型・必須/任意・制約>
- 出力: <戻り値・型・意味>
- エラー時: <どういう条件で何を返す・投げる・記録するか>
- 備考: <互換性・破壊的変更の有無>

ファイル書式・設定を新設する場合は具体例を添える。

```json
{ "<key>": "<value>" }
```
